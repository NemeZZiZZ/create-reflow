## Global Constraints

- BLE category byte = `0xBE`; verbs: 1002/1005/1008/1009/100A/100C (+100D/100F already live). OF sends EMPTY payloads on BLE GETs; our aux.ts convention sends `[0x00]` — implement GETs with `[0x00]` (our live-proven convention) and record the discrepancy in the module header; Phase-10 probe settles.
- Slot rules: index 1..4 selectable/clearable; slot 0 reserved (dongle) — never a target, shown as reserved; bounds+reserved pre-validated BEFORE the wire (refuse, don't send).
- Destructive discipline: `be/100A clear` is confirm-gated at the UI (danger tone) and never a scripted recipe action; select on an unconfirmed slot warns typing stops until USB-C/power-cycle. `be/1004` stays wire-guard-blocked (existing).
- 239B decode: never raises; wrong length ⇒ `{layout:null}` + raw hex passthrough; unknown bytes stay raw; only the fields listed in the brief are decoded (header/profile/split offsets below); vendor parser's extra EXPERIMENTAL fields are NOT imported.
- Capability cache: negative-only (`unanswered` ⇒ skip re-asking), keyed `(side, firmwareVersion)`, in-memory per session; a positive answer is always re-asked. Module battery reads are NOT cached (existing behavior unchanged).
- I/O log: SDK-side tap inside `roundtrip` (TX before write, RX per frame, error record on timeout/exception); bounded ring (~500); export = blob download via the existing `save.ts` pattern; NO OPFS.
- Verdict functions are PURE (no session access): pairing verdict takes both halves' identity+pair data; split-link verdict takes the pairing report + partner-probe result.
- Gates: sdk `tsc --noEmit` + `oxlint src`; client `tsc -b && vite build` + oxlint touched; smoke 0 FAIL from client/ (`export PATH="$HOME/.nvm/versions/node/v22.21.1/bin:$PATH"`), count grows exactly; `void main();` anchor preserved. UI copy English. Plain git, explicit paths, local main, never push. No hardware writes (dry-run/smoke only; live = Phase 10).

## Review Focus

2. **Decode never-lies** — wrong/short length ⇒ layout null + raw; unknown fields raw; flags decoded only from the pinned bit table; experimental fields absent. → T1 §63.
3. **Cache is negative-only and fw-keyed** — answered verbs re-asked; unanswered skipped without wire; new fw key re-probes; module battery uncached. → T1 §63.
4. **I/O log captures suppressed traffic** — records frames emitted while client `onFrame` is null (aux polls); timeout/error entries present; ring bounds enforced. → T2 §64.
5. **Verdict semantics** — pairAddress is the PEER's address (expected peer = partner's localAddress); bond-missing distinguished from no-table-read (unknown); ordered split-link states. → T1 §63.

### Task 1: SDK — BLE verbs + 239B decode + verdicts + capability cache

**Files:**

- Test: `client/scripts/smoke.tsx` — new `// §63 BLE: verbs, 239B decode, verdicts, capability cache`

**Interfaces:**
- Produces:
  - `bleGetStatus(): Promise<Frame>` (be/100C, params `[0x00]`), `bleGetAllPairs()` → `{count:number; macs:Uint8Array[]}` (guard `count<=8 && len>=1+6*count`; `[0]` = empty table, distinct from null), `bleGetPairAddress()`/`bleGetAddress()` → `Uint8Array|null`; `bleSelectProfile(idx)` — pre-validate idx 1..4, send be/1009 `[idx]`, then be/100C read-back `ok = activeProfile === idx`; `bleClearProfile(idx)` — pre-validate 1..4, send be/100A `[idx]`, read-back reports the slot's `hasPeerData` as `bonded`.
  - `decodeBleStatus(raw: Uint8Array): BleStatus` — layout 239 = header 15 + 5×37 + split 39; header: revision u32BE [0:4], profileCount [4], activeProfile [5], flags [6] (0x01 advertising, 0x02 hostConnected, 0x04 localAddrValid), localAddress MAC [9:15]; profile @15+i*37: index blk[0], activeFlags blk[1] (0x01 configured, 0x02 bonded, 0x04 connected, 0x08 active, 0x10 hasPeerAddr, 0x20 encrypted, 0x40 authenticated), securityLevel blk[2], hasPeerData=any(blk[5:]), peerAddress blk[6:12] when hasPeerAddr, raw 37B kept; split @200: peerAddress [4:10], connectionIntervalMs u16BE[10:12]×1.25, latency u16BE[12:14], supervisionTimeoutMs u16BE[14:16]×10. Big-endian. Never raises; wrong length ⇒ `{layout:null, rawHex}`.
  - `pairingVerdict(left, right)` — healthy = left.pairAddress equals right.bleAddress AND vice versa; one-directional = half-paired; bond-missing = addresses mutual but partner absent from be/1005 table; no-table-read = unknown (not failure).
  - `splitLinkVerdict(report, partnerProbe)` — ordered: connect-both → firmware-mismatch (repair refuses) → pairing-repair → link-down (probe not reached; EMPTY payload ≠ answer) → ok.
  - `BleCapabilityCache` class — `ask(side, fw, sub, fn): Promise<Frame|null>`; negative-only; fw-keyed; wired into `aux.ts` q() for be/1006/100f (stops re-asking unanswered verbs).
- Smoke §63: synthesized 239B fixture (self-validating profile indices), flag-bit asserts, wrong-length passthrough, verdict fixtures (all states incl. bond-missing vs unknown), cache behavior (unanswered skipped w/o wire — assert via counting fn calls; answered re-asked; new fw re-probes), slot pre-validation refusals, verb frame bytes byte-exact (`be 10 0c` + `00` param form asserted), wire-guard pass-through asserts for 1009/100A/100C.
